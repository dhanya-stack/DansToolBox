# Workbench

A single-repository static website containing practical interactive tools for money, fitness, habits and engineering.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create one GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` / root.
4. GitHub will provide the public URL.

All tools are plain HTML/CSS/JavaScript and require no build step.
